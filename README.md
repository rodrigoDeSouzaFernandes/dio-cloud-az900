# Resumo do que aprendi no laboratório – Localizando serviços por categoria

Neste primeiro vídeo do curso de fundamentos da computação em nuvem, explorei o portal do Azure e dei meus primeiros passos para entender a estrutura da plataforma. Abaixo estão os principais pontos que aprendi:

## Criação da conta gratuita
- Aprendi como criar uma conta no Azure com 30 dias de crédito e acesso a alguns serviços gratuitos.  
- Esse é o primeiro passo essencial para acompanhar os laboratórios do curso.

## Portal do Azure é universal
- Descobri que o portal que estou usando é o mesmo usado por grandes empresas.  
- A interface e os menus são idênticos, mesmo que alguns recursos estejam bloqueados por causa da conta gratuita.

## Personalização do portal
- Posso mudar o idioma e as cores do portal conforme minha preferência, acessando o menu no canto superior direito.

## Importância da nuvem na carreira de TI
- A computação em nuvem é essencial no presente das carreiras em tecnologia.  
- Seja em desenvolvimento, inteligência artificial, banco de dados ou infraestrutura, o domínio da nuvem é obrigatório.

## SLA e versões em preview
- Aprendi sobre o SLA (Acordo de Nível de Serviço), que representa a garantia de disponibilidade oferecida pela Microsoft.
- Recursos em versão "preview" não têm SLA e, portanto, não devem ser usados em produção sem consciência dos riscos.

## Localizando serviços por categoria
- Usei o botão **"Todos os serviços"** para visualizar os recursos do Azure organizados por categorias.
- As categorias incluem: Computação, IA, Banco de Dados, Rede, DevOps, Híbrido, Armazenamento, entre outras.

## Serviços em destaque

### Computação
- Máquinas virtuais  
- Discos  
- Chaves SSH  
- Conjuntos de disponibilidade  
- Imagens e contas de laboratório  

### Rede
- Azure Bastion (jump server seguro)  
- Gateways  
- Peering (emparelhamento de rede)  
- Load balancer  
- Firewall  
- DNS  
- ExpressRoute  

### Armazenamento
- Discos  
- Migração de dados  
- Serviços de backup e recuperação  

## Importância da configuração correta
- Mesmo sendo tudo virtualizado, os conceitos de infraestrutura continuam os mesmos.  
- É essencial configurar corretamente os recursos para evitar falhas ou problemas de segurança futuros.
